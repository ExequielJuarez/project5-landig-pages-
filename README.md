# Landing pages para profesionales

HTML/CSS/JS estático, sin dependencias. Abrí `index.html` para ver el listado.

- `veterinario/` · `abogado/` · `medico/` · `dentista/` · `psicologo/` · `nutricionista/`
- `assets/main.js` (menú móvil, animaciones, formularios → WhatsApp). Cada página tiene su propio HTML y CSS, con estructura distinta.

Para personalizar: cambiá textos, teléfono, dirección y el número de WhatsApp (`data-wa` del `<form>` y el link `.wa`, formato `5493510000000`). Nombres, matrículas y precios son de ejemplo.
